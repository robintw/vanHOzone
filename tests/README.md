# vanHOzone Tests

Comprehensive test suite for the vanHOzone package.

## Overview

This test suite provides comprehensive coverage for the van Heuklon (1979) Ozone model implementation, testing the `get_ozone_conc` function across a wide range of scenarios.

## Test Coverage

The test suite includes 33 tests covering:

### Basic Functionality
- Scalar inputs (single lat/lon/timestamp)
- Array inputs with single timestamp
- Array inputs with array of timestamps
- numpy array inputs
- Datetime object inputs

### Geographic Coverage
- Northern hemisphere locations
- Southern hemisphere locations
- Equatorial locations
- Extreme latitudes (Arctic and Antarctic)
- Different longitudes (East, West, Prime Meridian)

### Temporal Coverage
- Different seasons in both hemispheres
- Leap year dates
- Year boundaries (Jan 1, Dec 31)
- Various date formats (ISO, US, European, ISO 8601)

### Data Validation
- Return type verification (numpy arrays)
- Return shape verification
- Positive ozone value verification
- Error handling for mismatched array lengths

## Running the Tests

### Using unittest (built-in)

```bash
python -m unittest tests.test_vanHOzone -v
```

### Using pytest (if installed)

```bash
pytest tests/test_vanHOzone.py -v
```

### Running a specific test

```bash
python -m unittest tests.test_vanHOzone.TestGetOzoneConc.test_scalar_northern_hemisphere -v
```

## Expected Results

All expected test results were generated by running the actual implementation code to ensure accuracy. The tests verify that:

1. Ozone concentrations are calculated correctly for various locations and dates
2. The function handles different input formats (scalars, lists, numpy arrays)
3. Timestamp parsing works for multiple date formats
4. Seasonal variations are properly modeled
5. Hemisphere-specific calculations are correct
6. Error conditions are handled appropriately

## Requirements

The tests require:
- numpy
- python-dateutil

These are the same dependencies as the main package.
